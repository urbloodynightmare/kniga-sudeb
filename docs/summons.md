# Призванные существа — правила 2024

Карточки появляются в «Умениях и магии → Призванные» после подтверждения сотворения. Поддерживаются «Обретение фамильяра», «Поиск скакуна», «Гигантское насекомое» и духи заклинаний Summon Beast / Fey / Undead / Aberration / Elemental / Construct / Celestial / Dragon / Fiend. Форма и круг ячейки определяют статистику; обычные животные используют фиксированные блоки 2024, а духи — масштабируемые блоки своего заклинания.

Источники механики:

- [SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf), CC BY 4.0; атрибуция в основном README. Фамильяры, Find Steed, Giant Insect, Summon Dragon.
- [Официальные описания заклинаний 2024](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions).
- [Официальные блоки существ 2024](https://www.dndbeyond.com/sources/dnd/br-2024/creature-stat-blocks).
- PHB 2024, лицензированный справочник Roll20: [аберрантный](https://roll20.net/compendium/dnd5e/Monsters%3AAberrant%20Spirit?expansion=32231), [звериный](https://roll20.net/compendium/dnd5e/Monsters%3ABestial%20Spirit?expansion=32231), [фейский](https://roll20.net/compendium/dnd5e/Monsters%3AFey%20Spirit?expansion=32231), [нежить](https://roll20.net/compendium/dnd5e/Monsters%3AUndead%20Spirit?expansion=32231), [стихийный](https://roll20.net/compendium/dnd5e/Monsters%3AElemental%20Spirit?expansion=32231), [конструкт](https://roll20.net/compendium/dnd5e/Monsters%3AConstruct%20Spirit?expansion=32231), [небесный](https://roll20.net/compendium/dnd5e/Monsters%3ACelestial%20Spirit?expansion=32231), [исчадный](https://roll20.net/compendium/dnd5e/Monsters%3AFiendish%20Spirit?expansion=32231).

Текст карточек — краткое русское изложение механики. Названия заклинаний в существующем датасете могут отличаться; привязка по стабильному английскому slug. Никакие описания из импортированных файлов не исполняются как код.

## Ограничения и жизненный цикл

- Ячейка, применение предмета или Дикий облик расходуется только вместе с созданием существа. Отмена и неверная форма не расходуют ресурс. Договор цепи позволяет специальные формы без ячейки; Дикий спутник использует Дикий облик или ячейку и всегда имеет тип «фея».
- Один фамильяр, один скакун и один призыв с концентрацией могут существовать одновременно. Новый концентрационный призыв заменяет предыдущий. Завершение обычного заклинания с концентрацией также убирает прежний концентрационный призыв. Часовое сотворение фамильяра требует концентрации; быстрые классовые варианты её не требуют.
- При 0 хитов существо исчезает. Временно скрытый фамильяр сохраняет хиты; возвращение не тратит новый призыв. Долгий отдых убирает Дикого спутника и восстанавливает хиты и дневные применения оставшихся постоянных спутников. Отдых завершает часовые призывы.
- Длительность — **игровое время**, не часы устройства. Для окончания есть кнопка. Урон целям, состояния, материальные компоненты и эффекты на призывателя (например, общее сопротивление дракона) применяются вручную по карточке; календарного таймера и автоматического внесения в боевую сцену нет.
- Заклинания Conjure Animals и подобные в редакции 2024 создают области/эффекты, а не отдельные существа. Animate Dead / Create Undead и Animate Objects не входят в этот каталог: это создание/контроль существ и оживление предметов, а не представленные здесь заклинания призыва духов.
- Данные спутников сохраняются внутри персонажа вместе с личной книгой и резервной копией; доступны мастеру в полном листе только для чтения.

## Проверки

Тесты `tests/summons.test.mjs`: масштабирование по ячейкам, особые формы, реальные ресурсы и отказ без частичных изменений, совместное существование, отдых, сохранение и импорт. Мобильная проверка через настоящий интерфейс: выбор/отмена/подтверждение, хиты, регенерация, переключение форм, ритуал, перезагрузка, отсутствие горизонтального переполнения.
