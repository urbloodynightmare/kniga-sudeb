# Книга судеб

Русскоязычный лист персонажа для партии Авантюрина, совместимый с правилами 2024. Фронтенд на GitHub Pages; личные аккаунты и синхронизация через подключаемый проект Supabase.

## Возможности

- Пять классов и подклассов из пользовательского датасета: колдун / Аха, воин / чемпион, волшебник / воплотитель, друид / Круг спор, плут / вор.
- Прогрессия 1–20: вложенные выборы, черты, воззвания, бонусы характеристик, навыки и экспертиза.
- Автоматические модификаторы, бонус мастерства, хиты, защита, ячейки, ресурсы и отдых.
- Инвентарь, золото, портреты без обрезки, собственные атаки, способности и ресурсы.
- Личные заметки, предыстория, цели и дневник партии с автосохранением.
- Комнаты партии по приглашению, общий дневник с историей и архивом, общие игровые сводки участников и просмотр полных листов выбранных героев мастером.
- 339 заклинаний SRD 5.2.1: английские тексты и русские поисковые названия распространённых заклинаний.
- Резервная копия / импорт JSON, копирование листа, печать и броски костей.
- Адаптация для телефона и клавиатурная навигация.

## Запуск и проверки

Для локального запуска и проверок движка нужен Node.js 20 или новее. Браузерный бандл официального Supabase SDK уже включён в репозиторий. Для его пересборки и облачных тестов установите зависимости через `pnpm install`.

```sh
node scripts/serve.mjs
node --test tests/*.test.mjs
```

Откройте `http://127.0.0.1:4173`. На GitHub Pages публикуется корень ветки `main`.

## Сохранение

После настройки `app/cloud-config.js` каждый игрок регистрируется и видит только свою книгу. Row Level Security и функция записи ограничивают доступ текущим `auth.uid()`. Сохранение проверяет номер версии: старое устройство не перезаписывает новое состояние незаметно. Для подключения выполните [инструкцию Supabase](supabase/SETUP.md).

До настройки хранилища явно включена локальная версия. Персонажи сохраняются в `localStorage`, ключ `book-of-fates-v1`. Для обмена используйте экспорт/импорт. Импорт добавляет копии и не заменяет существующих персонажей. После включения облака локальные листы не загружаются автоматически в аккаунт: игрок импортирует нужный файл сам. Датасет можно заменить через «О книге и правилах».

Стартовые карточки — заготовки, не восстановленные личные листы. Характеристики основаны на стандартном массиве и требуют проверки игроком. Авантюрин начинает с 4-го уровня; уровень остальных игроков неизвестен и установлен в 1. Выбранный будущий подкласс активируется с 3-го уровня.

## Область автоматизации

Сайт вычисляет постоянные числовые эффекты структурированных правил датасета. Текстовые эффекты (преимущество, сопротивление, дополнительные атаки, условный урон, формы друида, ритуалы, подготовка книги волшебника) читаются в карточке и применяются игроком. Формула урона собственной атаки задаётся целиком; бонус атаки пересчитывается по характеристике и мастерству. Мультикласс и совместное редактирование одного листа несколькими аккаунтами не реализованы.

Во вкладке «Заметки партии» игрок создаёт комнату или присоединяется по приглашению. Создатель становится мастером и может передать роль участнику. Все участники видят сводку выбранных героев: характеристики, хиты, КД, инициатива, магия, спасброски, навыки и состояния. Только текущий мастер может открыть полный лист выбранного для комнаты героя, включая его историю и заметки, в режиме просмотра. Другие герои аккаунта и личный дневник книги не передаются. Дневник комнаты общий; прежний дневник аккаунта остаётся личным и переносится в комнату только отдельным действием. Записи сохраняются кнопкой «Сохранить для партии», а черновики — на устройстве при наборе. При конфликте версий можно сохранить свою редакцию отдельной записью. Подключение и проверки описаны в `supabase/SETUP.md`.

Класс/вид/подкласс применяются отдельно; снаряжение не дублируется при повышении уровня. Удалённые на низком уровне возможности сохраняются как выборы, но не влияют на расчёт. Неподходящие по требованиям выборы помечаются и не применяют эффекты. Ручные черты — явное исключение для домашних правил.

## Исправления поверх исходного датасета

Базовый набор хранится в `data/party.json`. Новые встроенные классы, виды и предыстории также добавляются адаптером к старым сохранённым копиям набора, не заменяя записи с совпадающим ID. Адаптер `normalizeDataset`:

- добавляет отсутствующие требования уровня воззваний;
- исправляет описания Мучительного/Отталкивающего разряда и Единства с тенями;
- раскрывает дополнительные выборы Договора гримуара, Уроков первых и заговора для воззвания;
- объединяет Ведуна друида с бонусами к обоим навыкам;
- исправляет владение оружием друида, спасброски плута на 15-м уровне и восстановление ресурса Убийцы магов;
- отдельно обрабатывает накапливаемый Пыл Радости: он не заполняется после отдыха.

Аха — домашний подкласс; Возрождённый и Круг спор — адаптации из предоставленного пользователем пакета.

## Источники

Пользовательский датасет: `aventurine_party_complete_2024.json`, версия 2.0.0. Названия и описания его домашних правил сохранены. Каталог заклинаний извлечён из официального SRD 5.2.1, страницы 107–175. Русские названия — дополнительные поисковые подписи.

This work includes material from the System Reference Document 5.2.1 (“SRD 5.2.1”) by Wizards of the Coast LLC, available at https://www.dndbeyond.com/srd. The SRD 5.2.1 is licensed under the Creative Commons Attribution 4.0 International License, available at https://creativecommons.org/licenses/by/4.0/legalcode.

Файл `scripts/extract-spells.mjs` воспроизводит извлечение каталога из текстовой выгрузки PDF. Сайт не зависит от PDF или инструментов извлечения.

В каждой комнате выбирается один собственный персонаж (или участие без героя). Переключение комнат сохраняет отдельные состояния свёрнутых блоков. При удалении комнаты её создателем все записи, включая архивные, сохраняются в личном дневнике каждого текущего участника отдельной копией.


### Готовые противники

Мастер комнаты во вкладке «Бой» выбирает уровень группы (1–20) и открывает библиотеку из 13 авторских шаблонов. По умолчанию предлагается средний уровень выбранных персонажей комнаты; ручной выбор запоминается для этой комнаты и аккаунта в текущем браузере. Растут хиты, КД, ведущая характеристика, бонус атаки и урон; дополнительные атаки открываются на 5/17 уровне, вторая особенность на 7, усиленные кости урона на 11, перебросок спасброска на 13. Это настройки шаблонов, не официальные статблоки или расчёт сложности встречи. Число противников задаётся отдельно.

«В сцену» добавляет независимые копии текущего уровня. «Изменить и сохранить копию» открывает обычный редактор и сохраняет карточку через существующий мастерский RPC в пул комнаты. Смена уровня библиотеки не изменяет существующие сцены и сохранённые карточки. Игрокам библиотека и приватные показатели участников не показываются. Новая миграция базы не требуется.


### Пассивная Проницательность и Сл манёвров

Пассивная Проницательность вычисляется как 10 + полный бонус навыка, включая владение и экспертизу; постоянное преимущество от надетого предмета даёт ещё +5. Для Сл манёвров в настройках персонажа выбирается характеристика (или лучший модификатор Силы / Ловкости) и отдельная поправка. Формула: 8 + мастерство + выбранный модификатор + поправка. Бонусы предметов к Сл заклинаний сюда не входят. Поле можно отключить, если у героя нет манёвров. Оба показателя публикуются в сводке комнаты; новые участники сцены получают их вместе со своей сводкой. Применить `supabase/character-metrics.sql` после миграции доступа к листам; обновлённые проверки входят в `character-access-check.sql`.


### Комнатная таблица лута

Во вкладке «Торговцы» текущий мастер видит «Случайный лут»: 100 авторских находок с ориентировочной ценой выкупа и описанием магических свойств. d100 бросает десятки (d%) и единицы, 00+0 = 100; отдельный d10 даёт 1–10. Таблица сворачивается, показывает по десять строк и ищет по всем 100. Название, цена и описание редактируются отдельно для комнаты. В базе сохраняются только правки к исходному набору, с проверкой версии. Броски остаются в текущем сеансе мастера. Игрокам блок не отображается, RLS и мастерский RPC закрывают доступ к комнатным правкам.

После `merchants.sql` применить `supabase/loot.sql`; `loot-check.sql` проверяет права, изоляцию комнат, смену мастера и конфликты версий в откатываемой транзакции.

## Пурпурная молния, монах, полуорк и благородный

[Правила домашнего подкласса](docs/purple-lightning.md) — законченная редакция 1.0 на уровнях 3/6/11/17, требующая игровых проверок баланса. Встроенный монах 2024 получает классовые возможности на уровнях 1–20, общий запас концентрации, автоматические КД без доспеха, скорость, кость и атаки. Кнопки техник списывают очки, у формы 17-го уровня — также применение до долгого отдыха; условия на поле боя, реакции и длительности отслеживает игрок. Числа для активной формы применяются вручную. Полуорк использует SRD 5.1 с происхождением 2024: прибавки характеристик 2014 не дублируются. Благородный 2024 добавляет Историю, Убеждение, игровой набор, Одарённого и выбор снаряжения. Одарённый поддерживает любые три навыка или инструмента. Набор и адаптер дополнений проверяются тестами `character-additions.test.mjs`.

Полуэльф доступен без наследия (два навыка) или с наследием высшего, лесного, водного эльфа либо дроу (заменяет эти навыки). Расовые заговоры имеют собственную магическую характеристику: Интеллект для высшего наследия, Харизма для магии дроу. Они не расходуют лимит заговоров класса.

В бонусах предыстории есть необязательная галочка «Свободное распределение». По умолчанию действуют характеристики выбранной предыстории; в свободном режиме стандартные +3 можно распределить между любыми шестью характеристиками, максимум +2 в одну и не выше 20. Режим хранится в листе для конкретного выбора предыстории; при отключении удаляются только прибавки вне её обычного списка. Черты и повышения характеристик на следующих уровнях этим переключателем не изменяются.


Раздел «Умения и магия» объединяет классовые активные способности, атаки, свойства мастерства оружия и прежний список заклинаний. Умения выводятся из реально полученных черт с учётом уровня и выборов. Применения расходуют общий ресурс; недостаток ресурса блокирует кнопку. Для собственных способностей можно выбрать ресурс и стоимость. Бесплатные и усиленные варианты монашеских приёмов разделены.

Автоматически учитываются лечение Вторым дыханием и Метаболизмом, временные хиты Симбиотической сущности и усиленной защиты, восстановление ячеек и концентрации, дневные применения и отдых. Условия попадания, цели, расстояния, состояния противников и ограничения «раз за ход» игрок проверяет по описанию: сайт не заменяет решение мастера. Тактический ум сначала позволяет бросить к10 без расхода и списывает заряд только по кнопке успешной проверки.

Мастерство оружия — свойства D&D 2024, не дополнительные действия BG3. Оно доступно при наличии соответствующей классовой способности и освоенного вида оружия. Выбор меняется через «Освоенное оружие»; для старых персонажей первоначально подставлены надетые подходящие виды в пределах лимита. Свойство видно рядом с атакой и в подробных условиях; снятие оружия убирает его приём. Само мастерство не делает обычный предмет магическим. Ключ вкладки и существующие сохранения заклинаний сохранены.


Навигация запоминает последний лист и вкладку каждого персонажа, поиск и фильтры библиотеки, прокрутку, раскрытые описания и свёрнутые крупные блоки. Кнопка «Герои» возвращает последний открытый лист; «Все персонажи» открывает список. Память интерфейса хранится локально отдельно для каждого аккаунта. Атаки и их добавление находятся только в разделе «Умения и магия». Крупные секции листа, ресурсов, умений, заклинаний и заметок можно свернуть, сохраняя их содержимое и доступность редактирования после раскрытия.


При выборе уже сохранённого героя в комнате обновляется только ссылка на персонажа; полная книга повторно не отправляется. Для нового локального героя выполняется синхронизация перед повторной попыткой. Тяжёлые портреты перед отправкой уменьшаются до 512 пикселей по длинной стороне и кодируются в WebP; исходная локальная книга при подготовке сетевого запроса не меняется. Неудачное декодирование сохраняет исходное изображение. Новые загружаемые портреты оптимизируются сразу. Ошибки сохранения различают тайм-аут сервера (57014), конфликт версии, ограничения данных, вход и сетевую ошибку.


Выборы одного варианта (включая черты и воззвания) сначала открывают описание без изменения персонажа. Вариант применяется только кнопкой «Подтвердить выбор». Недоступные варианты разрешено просматривать, но подтвердить их нельзя; требования проверяются повторно при подтверждении. В окне повышения уровня остаются и завершённые пункты текущего уровня, включая вложенные настройки: их можно пересмотреть до закрытия окна. Неподтверждённый просмотр можно отменить; при закрытии окна он не записывается в книгу.

### Призванные существа

В разделе «Умения и магия → Призванные» сохраняются фамильяры и духи заклинаний призыва, включая классовые варианты и применения предметов. Статистика масштабируется по потраченной ячейке. [Поддерживаемые призывы, источники правил и ограничения](docs/summons.md).
